      步骤 1：下载 CLI

      从本服务显式下载 zipapp，不要把安装脚本管道给 shell。密钥写入仅自己可读的文件。

      python3 -c 'from urllib.request import urlretrieve; urlretrieve("__ORIGIN__/install/flybot.pyz", "flybot.pyz")'
      Invoke-WebRequest -Uri __ORIGIN__/install/flybot.pyz -OutFile flybot.pyz

      步骤 2：启动守护进程

      下载完成后显式启动。把密钥放在 --key-file 里，不要写进 shell 历史。

      python3 flybot.pyz daemon start --origin __ORIGIN__ --key-file ./runtime-key
