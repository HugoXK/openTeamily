    步骤 1：安装 CLI

    命令指向当前 OpenTeamily 服务自己的安装路径，不会启动守护进程。这一页还不发布可执行的 FlyBot CLI，脚本只会说明后续步骤。

    curl -fsSL __ORIGIN__/install/flybot.sh | sh
    irm __ORIGIN__/install/flybot.ps1 | iex

    步骤 2：启动守护进程

    启动时需要上一步生成的密钥。请把密钥保存在你自己的环境里，不要贴回聊天记录。

    flybot daemon start --origin __ORIGIN__ --key <runtime-key>
