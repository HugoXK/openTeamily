完成连接

  1. 1. 下载 CLI

    从本服务显式下载 zipapp，不要把安装脚本管道给 shell。

    下载 flybot.pyz · 打开下载页

  2. 2. 启动守护进程

    把密钥放在 --key-file 里，不要写进 shell 历史。

    python3 flybot.pyz daemon start --origin __ORIGIN__ --key-file ./runtime-key

  3. 3. 完成连接

    守护进程登记并心跳后，会出现在下方列表。也可以打开「连接」生成密钥或发送测试任务。
