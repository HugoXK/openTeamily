FlyBot 运行时

在自己的机器上连接管理端。请显式下载 zipapp 再启动，不要把安装脚本管道给 shell。这里没有 Teamily 的地址。

下载 flybot.pyz

下载后显式启动，例如：

python3 flybot.pyz daemon start --origin __ORIGIN__ --key-file ./runtime-key

也可以使用源码树里的 python3 -m openteamily.flybot。运行时密钥在「运行时」页生成。
